# KairOS
A minimal Linux-based OS with a custom C shell: `go` (cd), persistent history, `ai` (AI chat with conversation memory, works out of the box via a rate-limited proxy — no API key needed), `nav` (interactive file browser), `gui` (Wayland desktop via weston + a terminal window), and a boot-time menu (Shell/GUI/Filesystem/Network/About). Ships as a bootable `KairOS.iso` (tracked via Git LFS).
